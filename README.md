# המופע של טרומן | תכנון תפאורה - הצגת י״ב אנתרופוסופית 🎭🌿

אפליקציה אינטראקטיבית ייעודית לתכנון, עיצוב וניהול תפאורה להפקת י״ב של **"המופע של טרומן"** בבית ספר אנתרופוסופי.

## 📌 אתגרי הבמה והפתרונות שנבנו
1. **במה ללא עומק ומאחורי קלעים צר:**
   - שימוש בשיטת **פריאקטי (Periaktoi)** מסתובב – עמודים משולשים עם גלגלים שקטים.
   - **קוביות עץ מודולריות:** 4 קוביות סנדוויץ' המשמשות למיטה, שולחן משרד, ספסל חוף, מושבי מכונית ומדרגות.
   - **גלי ים מבד משי:** יריעות משי כחולות המופעלות ע"י ניצבים בתנועה חיה, ללא צורך במבני דיקט כבדים.
   - **מסגרת מראה פתוחה:** מסגרת עץ דקה שטרומן מביט דרכה ישירות לקהל.

2. **שילוב התזמורת החיה (פסנתר, גיטרות, תופים):**
   - **מיקום מומלץ (חלופה א׳):** רצפת האולם משמאל לקדמת הבמה.
   - משאיר 100% ממאחורי הקלעים פנוי למעבר שחקנים.
   - מאזן את המדרגות היורדות לקהל בפינה הימנית.
   - מוקף במעקה עץ מעוגל ותאורת פחם חמימה כאולפן שידור חי.

3. **סצנת הסיום (קיר השמיים והדלת):**
   - חרטום סירת עץ קל ("סנטה מריה") על גלגלים.
   - קיר אחורי עם ציור עננים ושמיים בגווני Lazur אנתרופוסופיים.
   - דלת סודית בקו אפס עם הקיר ומדרגות עץ יציבות המובילות ליציאה אל החושך.

## 🚀 הפעלה
האפליקציה בנויה ב-Pure HTML5, CSS3 ו-JavaScript מודרני ללא תלויות خارجية:
1. פשוט פתחו את `index.html` בכל דפדפן (Chrome, Safari, Edge).
2. ניתן להפעיל ישירות ב-GitHub Pages דרך הגדרות המאגר:
   `Settings -> Pages -> Deploy from branch (main / root)`.
